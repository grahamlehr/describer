Theme

Theme options

A colour left on Default is the one in the theme’s own stylesheet, so it follows the theme if the theme is ever redrawn.

The Ceefax theme has no options of its own.

Amber was the only colour these panels came in, so the LED matrix has no options.

This board counts down in the text colour and has no separate on-time colour; its blue bars are structural and stay in the stylesheet.

Screen

Profiles

A different board at a different hour. Each profile changes only what it names; everything else comes from the Stations and Display tabs, which are also what runs when no profile matches.

    Tried top to bottom: the first one matching the moment wins, so an overlap is settled by the order. Move one with the arrows.

    The week

    What is on the screen at each hour. A gap is the base config from the other tabs.

    Failover

    The primary is used while it works. After enough consecutive failures the fallback takes over, and the primary is retried quietly in the background until it comes back.

    Realtime Trains

    The free tier allows 1000 calls a day shared by everything holding the token, so the floor below is obeyed whenever RTT is live.

    Endpoints and timeouts

    Credentials never live in this file. The Rail Data Marketplace key comes from RDM_API_KEY; Realtime Trains uses a bearer token in RTT_TOKEN, requested from api-portal.rtt.io.

    Announcements

    Spoken by Piper on the Pi itself, in platform phrasing.
