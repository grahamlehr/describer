Set up your departure board

Which station?

Type the station’s name and pick it from the list. You can show a second station beside it.

Your rail data key

Live train times come from the Rail Data Marketplace. It is run by the rail industry, and every board needs its own key. It takes about five minutes to get one, and you only do it once.

  1. Go to raildata.org.uk and create an account.

  2. Find the product called Live Arrival and Departure Boards. Don’t pick the departures-only one: it looks almost the same, but the board can’t use it.

  3. Subscribe to it. It’s free.

  4. Open your subscription and copy the Consumer key.

  5. Paste it here.

A key is saved. Paste a new one only to replace it.

Sound

The board can announce trains out loud, like a station.
